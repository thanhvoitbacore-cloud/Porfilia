# Porfilia - Agentic AI Personal Portfolio Generator

**Stateless & Privacy-First Agentic AI Portfolio Builder** built with Next.js 15, Tailwind CSS, and Google Gemini API.

## Features
- Stateless & Privacy-First Architecture (.json state import/export)
- Sequential Agent Confirmation Flow
- Pinterest-Inspired Art Director Style Engine
- Guided & Freeform AI Refinement Chat Modes
- High-Quality Client-Side PDF Generation

## Setup & Deployment
```bash
npm install
npm run dev
```
